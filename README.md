# JsonToolKit

[![Download](https://img.shields.io/badge/Download-latest-blue)](https://github.com/brotenet/JsonToolKit/releases)

A Java toolkit library for working with JSON data.


## Include JsonToolKit as Maven dependency
Add the following to your Maven **pom.xml** file to include JsonToolKit to the Maven dependencies of your project.
```xml
<repositories>
  <repository>
    <id>github</id>
    <url>https://maven.pkg.github.com/brotenet/JsonToolKit</url>
  </repository>
</repositories>

<dependency>
  <groupId>brotenet</groupId>
  <artifactId>json-toolkit</artifactId>
  <version>0.0.1</version>
</dependency>
```
